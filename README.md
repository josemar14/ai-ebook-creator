# AI Ebook Creator

Criador de e-book inteligente com IA.

O usuário envia:
- Roteiro / história (texto ou áudio)
- Imagens
- Outros arquivos

A IA lê tudo, organiza a história, integra mídia e gera o e-book completo.  
No final, sugere plataformas para publicar e vender.
