# Instruções para Claude, ChatGPT e chats avulsos

1. Faça upload / anexe o **Celebro.md do seu projeto** (não o template vazio).  
2. Cole o bloco abaixo em Project instructions ou Custom GPT Instructions.

---

## Texto para colar

```text
Celebro = memória viva do projeto (arquivo Celebro.md neste repositório / knowledge).

Regras:
- Antes de mudanças grandes ou quando eu disser "Celebro" / "cérebro", consulte o Celebro.md.
- Respeite stack, fluxos e decisões documentadas.
- Depois de bug fix, feature ou decisão de produto, sugira o patch em markdown do Celebro.md (com data de atualização).
- Não coloque tokens, senhas ou API keys no Celebro — só nomes de variáveis de ambiente.
- ROADMAP.md = fases e status (se existir); Celebro.md = como o sistema funciona; AGENTS.md = ponteiro multi-agente.
- Idioma: o mesmo do Celebro / do usuário (padrão PT-BR se o time for brasileiro).
```

Kit do método: https://github.com/josemar14/celebro
